Ember Yard is a round-based tactical FPS built with three.js: plant the spike at Site A or Site B, or eliminate the enemy team, across up to 9 rounds in a dusk dockyard. Four weapons, a grenade, a buy economy, and bots that patrol lanes, hold sites, investigate gunfire and defuse the spike.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
